# File narasi dari ElevenLabs

Folder ini untuk menerima hasil unduhan sebelum diperiksa dan diintegrasikan. Buat satu file audio per halaman dan bahasa. Gunakan format MP3 jika tersedia; pertahankan file asli tanpa mengedit atau mengubah durasi.

Untuk audisi pertama, simpan sapaan bahasa Indonesia sebagai `welcome-id.mp3`. Naskah dan nama lainnya direncanakan sebagai berikut:

| Halaman | Indonesia | English | Korea |
|---|---|---|---|
| Sapaan pembuka | `welcome-id.mp3` | `welcome-en.mp3` | `welcome-ko.mp3` |
| Pengertian karhutla | `karhutla-definition-id.mp3` | `karhutla-definition-en.mp3` | `karhutla-definition-ko.mp3` |
| Penyebab | `karhutla-cause-id.mp3` | `karhutla-cause-en.mp3` | `karhutla-cause-ko.mp3` |
| Pencegahan | `karhutla-prevention-id.mp3` | `karhutla-prevention-en.mp3` | `karhutla-prevention-ko.mp3` |
| Penutup | `closing-id.mp3` | `closing-en.mp3` | `closing-ko.mp3` |

Naskah lengkap ada di [naskah narasi](../../../../docs/client-revisions/2026-10-30/narration/naskah.md). Sapaan/penutup masih draf dan teks konten dapat berubah mengikuti klien. Sebaiknya buat sapaan Indonesia terlebih dahulu untuk audisi sebelum membuat sisanya.

Catat model, voice, pengaturan, tanggal, teks, dan kredit aktual dari ElevenLabs jika terlihat. Jangan menaruh API key atau informasi akun di folder ini. File di folder ini belum otomatis terintegrasi ke game.
