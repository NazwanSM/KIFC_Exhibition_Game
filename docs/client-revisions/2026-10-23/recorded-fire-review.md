# Rekaman api pemilik — penerapan lintas layar

Tanggal: 23 Oktober 2026. Status: **Ditinjau**, implementasi lokal.

## Perubahan

- Seluruh renderer api bergerak memakai rekaman pemilik `33072-395456627.mp4`: assembly setelah lengkap, KIFC-03 penjelasan, demo pengurangan unsur, dan simulasi rambatan/sekat bakar. Ikon statis dan foto materi lain tetap menjalankan perannya.
- Runtime memakai turunan **animated WebP transparan**, bukan pemutaran MP4 langsung. Ukuran 480×180, rasio 8:3 dari crop area api, 15 fps, 300 frame/~20 detik, loop tanpa suara; 7.15 MB dibanding sumber 30.66 MB. Sumber MP4 tidak diubah. [Metadata](../../../build/fire-video-review/asset-metadata.json). Proses reproducible dan status sumber di ASSET_SOURCES.md.
- Latar hitam dihapus dengan alpha feathering; tepi bawah dilembutkan saat compositing. Api tidak diregangkan atau diberi gerakan mesh tambahan. Pada panel 190px, api lebih lebar dan ditempatkan di area atas; tiga foto tetap sebaris dengan rasio 1.8, label dan indikator jumlah tidak tertutup.
- Saat unsur dikurangi, rekaman mengecil ke 35% dengan dasar tetap tertambat. Pada rambatan, area tampak mengikuti progres dan tepinya dilembutkan; setelah pemisahan bahan bakar, nyala tidak melewati sekat. Narasi, skor, timer dan rute tetap sama.
- Animasi berhenti meminta frame ketika TickerMode tersembunyi atau aplikasi tidak aktif. Reduced motion memakai poster transparan dari rekaman pada detik 2. Tidak menambah plugin video, audio, fog atau jaringan runtime.

## Pemeriksaan

- Seluruh **168 tes lulus**: [log suite](../../../build/fire-video-review/suite.log).
- Assembly akhir: [15 tes dan capture terbaru](../../../build/fire-video-review/assembly-final.log).
- Capture khusus lima keadaan × lima ukuran × tiga bahasa: **15 tes lulus**: [log visual terbaru](../../../build/fire-video-review/visual-final.log). Tes tambahan memeriksa ukuran hasil transform api benar-benar menyusut, bukan hanya flag state.
- Analisis Flutter bersih: [log](../../../build/fire-video-review/analyze-final.log).
- Tes codec mendekode frame yang berbeda, mengecek alpha transparan dan opaque, rasio, durasi frame dan loop tak terbatas. Tes reduced-motion/lifecycle serta tes pixel memastikan nyala yang sudah dihentikan tidak berada di sisi seberang sekat.
- Helper screenshot disesuaikan agar gambar animasi bisa menerima pump pada frame clock. Screenshot sesudah pengurangan menunggu transisi skala selesai.
- Server web direstart penuh. Kedua aset ada di manifest, HTTP 200, SHA256 sesuai lokal: [bukti pengiriman](../../../build/fire-video-review/web-assets.json). [Screenshot browser aktual 674×923](../../../build/review-fire-video/browser-explanation-id-674x923.png).
- Screenshot matriks berikut adalah **render UI Flutter dari widget test**. Bukan foto perangkat TV 42 inci. Simulasi 1080×1920/2160×3840 tidak membuktikan jangkauan fisik atau performa perangkat. Belum ada APK/deploy baru, profil GPU Android, atau uji TV fisik.
