# Babak 1 — empat layar sesuai mockup 24 Oktober 2026

Status: implementasi lokal siap ditinjau. Urutan **memilih unsur → feedback 3/3 → penjelasan segitiga api → mengurangi unsur** tetap sama.

## Perubahan dan hasil pemeriksaan

- Panel hutan bersama diperbesar menjadi 248 logical px (216 pada viewport pendek), foto tetap proporsional. Bagian lantai hutan dicrop agar berada tepat di atas kartu. Tiga kartu sejajar di dasar panel, placeholder memakai bidang krem dan tanda tambah, tanpa membocorkan kategori.
- Enam titik api memakai tiga potongan video 237888.mp4, berukuran/depth berbeda, dengan mirror dan fase rekaman berbeda. Sumber video ~74.7MB tidak dibundel; tiga loop transparan hanya ~1.76MB. Ukuran/frame/transparansi dan perbedaan fase diperiksa melalui codec.
- Tidak ada api sebelum tiga unsur benar lengkap. Komponen ForestFireSimulation dipakai oleh feedback 3/3, penjelasan dan demo. Api berangsur mengecil/pudar hingga padam untuk ketiga faktor. Pergantian cepat mempertahankan intensitas saat itu; mencoba faktor lain setelah padam memulai demo dengan penyalaan kembali yang halus.
- Maskot diperkecil sesuai ruang dan tidak menimpa CTA. Halaman pengurangan unsur kini sejajar atas tanpa whitespace besar di atas foto. Narasi tetap utuh; progres 3/3 tetap terlihat, demo tanpa skor. Auto-lanjut setelah ketiganya dicoba memberi 2,6 detik agar animasi selesai.
- Drag semua pilihan, alasan pengecoh, pengisian posisi bebas, sentuh untuk lanjut sesudah lengkap, Kembali/Ulangi, waktu baca, serta urutan babak tetap berfungsi.
