# KIFC-G04 audio implementation plan

**Goal:** Add downloaded, licensed offline music, nature ambience and short UI effects, controlled from a shared sound panel.
**Architecture:** A session-owned controller with an injectable backend serializes loop/lifecycle changes. A native/web audioplayers adapter keeps two loop players and one bounded effects player. The game routes semantic effects; selection in the timed challenge stays neutral. Shared header controls use the existing centered touchscreen layout.
**Tech stack:** Flutter/Dart, audioplayers6.5.1 (compatible with current Flutter), MP3/WAV offline assets, FFmpeg for format/level/loop preparation only.
**Spec:** docs/client-revisions/2026-10-23/kifc-g04-audio-scope.md plus direct owner instruction to proceed with audio and download existing recordings. This supersedes postponement; original audio synthesis and voice-over are excluded.

## Decisions
- PackageC (music+nature+effects) from the tracked client request; no paid assets or generation. Provenance and source licenses archived.
- One sound icon in the shared header; modal centered volume controls for master/music/nature/effects plus mute. Default master45%, music35%, nature45%, effects70%; mixer multiplication keeps initial levels low.
- Settings survive page/language/replay within application lifetime; fresh application starts at defaults. No persistent storage dependency or system-volume changes.
- Preload only sources; start after a visitor gesture. Mute/zero/background immediately silences all output, restores only allowed loops, never replays old effects. Opening controls does not change game flow/timer.
- One transient effect at a time, cooldown on repeated taps; correctness only at actual answer feedback, never on final selections or unscored cards/demo.
- Keep existing order, scoring and interactive timers unchanged. Failure to play audio cannot block gameplay; sound panel offers retry after an error.
